# Naija Tax Guide - Tax Content Update Log

Purpose: track meaningful changes to tax-answer policy, source discipline, reviewed-answer content, and safety wording.

This log is not a substitute for official tax authority updates. It is an internal product-control record showing when Naija Tax Guide reviewed or changed its guidance posture.

## Log format

Each entry should include:

- Date
- Area reviewed
- Change type: source update / answer correction / safety wording / new benchmark / expert review / legal-page update
- Risk level: low / medium / high
- Source category
- Reviewer or owner
- Summary of change
- Follow-up required
